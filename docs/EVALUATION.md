# 求职智囊 Agent · 系统完善度评估报告

> 评估方式：4 条真实场景输入并行实测（真实 LLM，通用兼容协议端点）+ 64 项既有测试证据 + 代码级审查
> 评估中发现 1 个 P0 并发缺陷，已当场修复并回归验证（详见三-3）

---

## 1.【总评】

**综合完善度：74 / 100** —— 单用户串行场景下工程可靠性和可观测性已达到可演示、可日常使用的完成度（异常自愈与全轨迹直播是亮点），但在**跨会话长期记忆、Prompt 注入防护、报告隐私边界**三处存在明确短板，多用户并发场景曾有事件串台缺陷（本次评估发现并已修复）。

## 2.【各维度得分表】

| 维度 | 得分 | 关键问题 |
|---|---|---|
| 一、意图识别与任务分解 | 4.0 / 5 | 无独立意图分类层，非求职输入也进规划器；"投递"类无工具支撑 |
| 二、工具调用准确性 | 4.0 / 5 | 自动注入+重试+熔断实测有效；缺入参 schema 静态校验 |

| 六、工程化与可观测性 | 4.5 / 5 | 缺持久化执行日志、失败率监控与 Bad Case 归因工具 |

## 4.【优先改进项 Top 5】

> **状态更新（本轮已实施）**：#1 跨会话长期记忆 ✅、#2 注入防护（输出脱敏+提示词安全声明）✅、#4 意图分类前置 ✅、#5 条件分支规划 ✅、#3 报告隐私部分实施（gitignore + PII 脱敏；隐私模式已支持会话不落盘）。回归 77/77 通过。

| # | 改进项 | 方案 |
|---|---|---|
| 1 | **跨会话长期记忆** | 新增全局画像层 `data/profile.json`（加密）：会话结束时将 facts 合并进全局画像，新会话启动时注入；与现有会话级 facts 分层（全局=偏好/资料，会话=临时材料） |
| 2 | **Prompt 注入防护** | 用户消息以 `<user_data>` 定界符包裹并声明"定界符内是数据非指令"；输出侧增加关键词检查（系统提示词/密钥/ignore instructions）；规划 JSON 校验已有限，补工具白名单 |
| 3 | **报告隐私边界** | `data/reports/` 加入 .gitignore；报告文件名与内容可选脱敏（姓名/电话打码）；提供"隐私模式"开关（不落盘） |
| 4 | **意图分类前置层** | 消息入口加一次轻量 LLM 分类（求职任务/闲聊情绪/数据指令/注入嫌疑），闲聊走共情短回复（省规划成本），情绪走支持路径——补齐人设中"情感支持"承诺 |
| 5 | **条件分支规划** | 规划 JSON 增加 `condition` 字段（如 `{"if": "score>80", "then": "t5", "else": "t6"}`），执行器求值跳转——覆盖"薪资高于30K就投递否则优化"类场景 |
